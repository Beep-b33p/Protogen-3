# Protogen-3
Protogen code! This will be the repository where I upload the code and other documents for my fursuit! :3

  A quick synopsis-
    Two microcontrollers, one in the head of my fursuit and a glove that'll act as a remote control.
      The head will drive the displays, as well as store the faces and cycle through them. The face will also have a sensor in the front, likely infared that will update to a special face. I'll program and install a small display in order to monitor the status of the screens, which face is displayed, battery life left in both the glove and head, and fan speed.
      The glove will have hall effect sensors, so when i close a finger, a different face will be for each. Right now it's just set up to work with buttons and the physical glove. 
      The two communicate over Bluetooth Low Energy, and the programming for that alone took awhile.
